# Triki — веб-застосунки на BLE-датчику Żabka Triki

Два самодостатніх Web Bluetooth застосунки для кришки-датчика Triki
(Nordic nRF52810 + ST LSM6DSL). Усе рахується в браузері, сервера немає.

| Застосунок | Посилання | Що робить |
|---|---|---|
| **IronCap** | [`ironcap.html`](ironcap.html) | Тренажер для залу: підрахунок повторень і TUT, контроль крену грифа, втома за швидкістю (VBT), таймер відпочинку |
| **Каденс** | [`index.html`](index.html) | Каденс педалей на велосипеді |

## Як відкрити на телефоні

iOS Safari **не підтримує** Web Bluetooth. Потрібен браузер
[**Bluefy**](https://apps.apple.com/app/bluefy-web-ble-browser/id1492822055).
На Android працює звичайний Chrome.

Datchik спить, щоб берегти батарейку — **натисни кнопку на кришці**
просто перед підключенням, інакше пристрій не з'явиться у списку.
Triki тримає лише **одне** з'єднання: якщо він підключений до ПК,
телефон його не побачить.

## Формат даних

Кадр 14 байт, Nordic UART Service (`6e400001-…`):

```
[0]=0x22  [1]=кнопка (0x00 відпущена / 0x01 натиснута)
[2..7]   гіроскоп     X,Y,Z  int16 LE  → ÷131.0  = °/с
[8..13]  акселерометр X,Y,Z  int16 LE  → ÷2048.0 = g   (діапазон ±16 g)
```

Команда запуску потоку в характеристику `…0002`:
`20 10 00 D0 07 68 00 03` (байт 5 = частота: `0x68` = 104 Гц).
Світлодіод — характеристика `…0004`, біт 0.

Нотифікації приходять пачками по кілька кадрів із довільним зміщенням,
тому парсер **сканує заголовок**, а не читає фіксовані офсети.

## Локальний запуск

```bash
python -m http.server 8765
```

Далі `http://localhost:8765/ironcap.html`. Web Bluetooth вимагає
захищеного контексту — `localhost` і `https` підходять, звичайний `http`
на локальній мережі ні.
