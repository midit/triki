Button on the cap:
1 click — start / finish a set
2 clicks — cancel the set (don't count it)
hold ~1.2 s — finish the workout

Nothing is counted outside a set, so walking between machines and racking the weight never reach your stats.

iOS: needs the Bluefy browser — Safari has no Web Bluetooth. If your sensor doesn't appear, wake it first (most sleep to save the cell).

Supported sensors: any Nordic UART (NUS) compatible IMU beacon that streams accelerometer + gyroscope — e.g. Holyiot / MINEW nRF52 beacons, or the Żabka bottle-cap puck. You connect your own device; IronCap only reads its motion stream.
